# СВЧ-дайджест — 27.07.2026

## 1. PHY-аутентификация для Ambient IoT в системах XL-MIMO с обратным рассеянием в ближнем поле

**Категория:** Антенны  
**Источник:** arXiv — RF, antennas and microwave engineering — RSS fallback  
**Оригинал:** https://arxiv.org/abs/2607.22134

Предложена схема бинарной элементной задержки (EW-DSK) для аутентификации устройств обратного рассеяния, использующая геометрически-зависимые физические сигнатуры сферических волн ближнего поля в системах XL-MIMO.

**Почему это важно:** Метод позволяет повысить безопасность и надёжность идентификации устройств в масштабных MIMO-системах с обратным рассеянием.

## 2. Линейные аналоговые СВЧ-вычислители для коммуникаций: возможности и вызовы

**Категория:** СВЧ-компоненты  
**Источник:** arXiv — RF, antennas and microwave engineering — RSS fallback  
**Оригинал:** https://arxiv.org/abs/2607.22509

Рассмотрена концепция переноса части обработки сигналов из цифровой области в аналоговую с помощью линейных СВЧ-сетей, способных выполнять вычисления непосредственно на радиочастоте.

**Почему это важно:** Это решение может существенно повысить масштабируемость и энергоэффективность будущих систем с большими антенными массивами.

## 3. Непрерывное отслеживание фазового шума внутри символа для THz OFDM с помощью полиномиальной реконструкции

**Категория:** СВЧ-компоненты  
**Источник:** arXiv — RF, antennas and microwave engineering — RSS fallback  
**Оригинал:** https://arxiv.org/abs/2607.22111

Предложен метод компенсации фазового шума Винера в терахерцовом диапазоне, учитывающий изменчивость фазы внутри OFDM-символа через полиномиальную аппроксимацию фазовой траектории.

**Почему это важно:** Метод улучшает качество передачи в THz-системах 6G, где традиционные методы компенсации фазового шума оказываются недостаточными.
